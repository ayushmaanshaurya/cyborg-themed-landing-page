
# CYBORG – Beyond Human Limits

A futuristic, responsive cyborg-themed landing page developed for the Techfest IIT Bombay Web Development Task.

## Features

- Futuristic cyberpunk-inspired UI
- Responsive navigation
- Animated hero section
- Interactive technology cards
- Smooth scrolling
- Responsive desktop and mobile layouts
- Neon glow and glassmorphism effects

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Project Structure

cyborg-landing-page/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.

## Purpose

Created as a web development project for Techfest, IIT Bombay.
